# Signal Yard

An original real-time grid battle prototype.

Run `python3 -m http.server 8765 --bind 127.0.0.1` from this directory and open http://127.0.0.1:8765. Use the arrow keys and Z/X or the touch controls.

Run `node --test tests/*.mjs` and `node --check client.mjs` to verify the simulation and client syntax.
