# 0.50.0 — Regular Chip

- **Regular Chip.** In Folder Edit, press **Select** (the new Select button; C or Shift on a keyboard) on a folder chip to make it the folder's Regular. Press it again to clear it.
  - A chip can be the Regular only if its MB is within the Regular memory. Otherwise a message says it is too big. This check is the game's (sub_8134A00: chip MB ≤ RegUP, Navi stat 9). The message wording is the app's own, because the game's folder messages are compressed text that isn't decoded yet.
  - The game's REG frame (sprite blob 0x203526C, sequence 0; sequence 1 is TAG) is drawn round the Regular chip's row at the game's position: x 165, y 40 + 16·row, origin (69,8) (sub_81353DC → sub_81348DC).
  - Each folder keeps its own Regular (as the game does: Navi stat 0x2E + folder, 0xFF = none). It is cleared if the chip in that slot is swapped for one too big.
- **Regular memory "4MB"** next to the folder name, on Folder Edit and Chip Folder, in the game's sprite number font: OBJ tiles 0x161–0x16A (digits) and 0x16C–0x16D ("MB"), OBJ palette 8 (0x8134500–0x8134518).
  - The starting values are rom-verified from initNaviStats_WithDefaultStatsMaybe_8013438: RegUP 4, MegaLevel 5, GigaLevel 1. This also upgrades the 5 MegaChip / 1 GigaChip caps from recalled to rom-verified.
  - RegUP items aren't modelled yet, so the memory stays at 4 MB.
- **In battle** (sub_800A350 / sub_800A570, rom-verified):
  - The Regular chip is swapped to the front of the battle folder and left out of the shuffle, so it is always in the first hand.
  - GigaChips are now shuffled apart and each inserted at index 10 + rnd % (count − 12), so they never come in the first hand.
- The small row MB digits no longer carry the row's dark background (colour 13 left transparent).
