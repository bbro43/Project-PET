# 0.71.0 — Anti-chips and the return to the menu

## Added
- **Back to the menu:** 3 seconds after YOU WIN! (or "MegaMan deleted..."), the battle closes and the menu returns.

## New chips
All traps are set inside a time freeze and stay hidden until something springs them. One trap at a time; a new one replaces the old.
- **AntiDmg:** the next hit of 10 or more is cancelled. MegaMan hides and throws a shuriken at the attacker for the chip's damage.
- **BodyGrd:** same trigger. MegaMan hides and 10 shurikens rain on the enemies, one every 20 frames, each for the chip's damage.
- **AntiSwrd:** the next sword hit is cancelled. MegaMan is invincible and sends 3 sword waves down his row, 22 frames apart. Sword attacks here: Swordy's slash, ProtoMan's slashes and Colonel's Screen Divide (which enemy attacks the game flags as swords is our reading, not traced).
- **ElemTrap:** the first Fire / Aqua / Elec / Wood attack that hits MegaMan sets it off; every enemy takes the chip's damage in that element. The hit itself still lands. In the game it springs when the attack touches any panel; here it only sees hits on MegaMan.
- **AntiNavi / AntiRecv:** set like the others, but they answer the opponent's Navi and recovery chips. The CPU enemies use no chips, so they never spring.
