# 0.71.1 — Sword attacks and ElemTrap, from the ROM

## Fixed
- **Which attacks count as swords (AntiSwrd):** now read from the game. Every attack carries a collision type; the type table (byte_8019C7C) gives its flags, and AntiSwrd springs on flag 0x2000 without 0x20000. That makes types 7, 0x11, 0x1C, 0x28, 0x40, 0x42, 0x45, 0x50, 0x53 and 0x54 swords. Enemy attacks using them:
  - Swordy's slash, DarkMech's slash, Nightmare's scythe.
  - ElecMan's dash strike, SlashMan's claw combo, rolling slash and kunai, EraseMan's scythe, TomahawkMan's axe throw and swing, ProtoMan's slashes, Colonel's Screen Divide, Bass's Dark Arm Blade, Cybeast Gregar's Beast Breath (0xC).
  - Not swords: TomahawkMan's chop waves, every other Navi and virus attack.
- **ElemTrap:** springs on any enemy Fire / Aqua / Elec / Wood attack aimed at the panels, whether or not it hits MegaMan (the game's trap covers every panel, region 0x80, target type 0x18). It also springs while MegaMan is invincible.

## Still approximate
- A few enemy hazards only check MegaMan's own panel; those spring ElemTrap only when they hit him.
