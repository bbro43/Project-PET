# 0.35.0 — panel graphics from the ROM

- The battle field now uses the game's own panel graphics, decoded on the device from the imported ROM (first available in the sprite order). All 13 panel types (none, broken, normal, cracked, poison, holy, grass, ice, volcano, four roads), both sides, all three rows, plus the palette animations (poison bubbling, holy shimmer, road arrows).
- Located with the owner's panel sheet as a reference: palette search → BG palettes 0x6E08F8, tiles LZ77 0x6DDBA0 (→ VRAM 0x6001460), per-type tilemaps byte_86DFA98 (0x800C01C), palette animations 0x800C1DC (0x800C192). Gregar offsets are the same data 0x207C lower. Every panel type, side and row, and every frame of the poison, holy and road animations, matches the sheet pixel for pixel. The sheet itself is not stored in the repo (art policy).
- Type 8 is a crater that erupts, so "Lava" is now **Volcano** (in the Field menu and the rules).
- Without a ROM the panels are still drawn as before.

Tests: 172 passing; ROM checks 3/3. Browser check of every field preset: no errors.
