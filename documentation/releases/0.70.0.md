# 0.70.0 — The missing pieces, the barrier's position, and batch 11

## Added (missing from 0.69.0)
- **Time freeze and chip name:** the special chips (barriers, Invisibl, panel chips, cubes, and this batch) now stop time and show their name before acting, like AreaGrab. Each one waits inside the freeze for as long as the game's object does.
- **Blinking panels:** HolyPanl, Snctuary and PnlRetrn blink every 4 frames for 64 frames before the panels change.
- **Barriers stop the whole hit:** a hit that breaks a barrier no longer passes its leftover damage to MegaMan; the game discards the whole hit. This also applies to FstBarr.
- **IceCube:** confirmed from the ROM that it uses its own ice-block animation; the earlier picture just showed the rock cube still on screen.

## Fixed
- **Barrier position:** the barrier is now drawn at MegaMan's own position, 2 pixels up, as the game places it. Before, it sat 16 pixels too high and off-centre.

## New chips
- **SloGauge / FstGauge:** MegaMan's custom gauge fills at half or double speed for 8 seconds. In link battles the game also slows or speeds up the opponent's gauge, but there's no opponent gauge against the CPU.
- **TimeBom1–3 / TimeBom+:** a bomb on the first free enemy panel ahead in MegaMan's row. It counts down for 3.5 seconds, then hits every enemy on the enemy side. It has 50 HP (TimeBom+ 200); destroyed first, it does nothing.
- **Fanfare / Discord / Timpani / Silence:** a music box on the panel ahead (60 HP, 40 seconds). It repeatedly gets ready, plays, then rests.
  - **Fanfare:** MegaMan is invincible while it plays.
  - **Timpani:** the enemies are held still while it plays.
  - **Discord and Silence:** these confuse Navis and stop them using chips. The CPU Navis here have neither confusion nor chips yet, so for now these two only play.
- **Geddon:** inside the freeze, every panel except MegaMan's breaks, one every 8 frames, in a shuffled order.
