# 0.25.0 — 27 Nov 2026 (asset pack 29)

The last two gaps from the Navi audit.

**TenguMan's dash follows the ROM's paths** (0x80F9B4C). It used to run down MegaMan's row from the right edge.
- Base version: a straight run along the top row, or along the bottom row when MegaMan is there.
- EX and up pick a path from MegaMan's panel: the top-row run (back middle), a diagonal climbing up-left (back top / middle top), or a diagonal coming down-left (anywhere else). Each diagonal moves one row per column.
- Speed is 10 px per frame (base) or 12 (EX and up), from the ROM. The path is lit for 20 frames first, and he can't be hit while dashing.

**ElementMan's elements and attacks:**
- **Element changes follow a fixed cycle** (0x81008C2): none → wood → fire → elec → aqua → none. They no longer pick at random. His palette changes to match (purple, green, red, yellow, blue), with the ROM's white flash and timings (19 / 20 / 10 / 10 frames).
- **His basic attack is a tornado** (type3 0x90, sprite 0x10/0x42), not the tower. It starts in his back column, runs 5 panels toward you, crosses 2 rows, then comes back 6 panels. Speed is 4 / 4.5 / 5 / 5.5 px per frame, and the leg lengths come from the ROM.
- **The fire attack uses his own fire tower** (sequences 18/19, as type3 0x8F loads it).
- **The aqua attack drops meteors** (sprite 0xC/0x31, which type3 0x8D loads). The wood attack shows its sparkle (sprite 0x10/0x0F, from type3 0x8E).
