# 0.67.0 — Navi Customizer compression codes, a shorter list, RUN inside the board, and the STATUS screen

## Navi Customizer
- **Compression codes:** each program's code is read from the game (10 presses of A / B / L / R). Highlight the program, hold Right on the D-pad and press the buttons in order. Entering the same code again switches the program back to its normal shape. Codes are saved on the phone. The app's old Select shortcut, which let any part compress, is gone.
- **Placed programs leave the list:** a program on the board no longer shows in the list. Removing it, or picking it up to move it, puts it back.
- **RUN:** the animation band now stays inside the board, between the frame's edges. It no longer covers the frame or the list.

## STATUS screen (new, menu → Status)
- The game's own STATUS screen, decoded from the imported ROM: its frame, panels, HP box and digits, page arrow, chatbox, and MegaMan's mugshot. Gregar's screen is green and Falzar's is orange, as in the games.
- **MegaMan page:** HP (100 plus HP programs), MegaMan, and the buster's Attack / Speed / Charge levels and charge shot ("Pwr ChargeS").
- **Folder page** (press Right): Reg.Mem, MegaChip, GigaChip, and the installed programs, 4 at a time (L / R scrolls).
- The labels are the game's own words, but they're drawn in the battle font because the menu font isn't decoded yet.
