# 0.80.0 — Road panels: ComingRd and GoingRd

## New
- **Road panels:** an object standing on a road slides one panel in the road's direction (4 frames), waits 5 frames, and goes again until something blocks it. This works for MegaMan and for the enemies, as in the game. FlotShoe keeps MegaMan off them. Roads turn back to normal panels after 30 seconds.
- **ComingRd:** every enemy panel becomes a road toward MegaMan, so the enemies get carried up to the front.
- **GoingRd:** every enemy panel becomes a road away from MegaMan, so the enemies get carried to the back.

## Fixed
- **Ice:** sliding now takes 4 frames per panel, as the game's movement code does. It was a guessed 6.
