# 0.46.0 — the game's custom gauge and HP box

- **Custom gauge with its "CUSTOM" label**, decoded on device: layout word_801ED6C (18×2 tiles at column 6), tiles 0x86E489C and 0x86E4C1C (0x801DF32), palette 9 = dword_86E1C78. The fill follows the game (0x801C640). On the game's 0–0x4000 scale, whole tiles 0x922A fill up to the value >> 10, with partial tile 0x9222 + ((value >> 7) & 7).
- **Gauge colour by fill level** (0x801C5F4): below 0x1500 the base palette; then 0x86E1CD8 below 0x2A00, 0x86E1CF8 below full, and 0x86E1D18 when full. The game also plays a sound at each step; there is no audio yet. The app's "L/R" hint is gone, as the game shows none.
- **HP box**: layout byte_801EDFC (6×2 tiles) with tiles from 0x86E1638 (loaded to 0x600B400 by list off_801ECB4) and palette 13. HP digits are the 8×16 digit tiles with their background colour left clear.
- **Text colours corrected**: BG palette 0 is at 0x3001960, so palette 13, used by the chip name line, is dword_86E1C78 (loaded to 0x3001B00), not byte_86BEC80. The colours look the same: entry 1 white, entry 2 dark.
- Gregar: all at −0x207C; the layouts are at the same offsets in both versions.
- **The losing message's strip**: the game has no such message. When MegaMan is deleted, the screen goes to the game-over sequence, which isn't traced yet. The app's text and strip are kept as a stand-in.

Tests: 182 passing. Browser check with the ROM: no errors.
