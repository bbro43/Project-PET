# 0.82.0 — ColorPt and DblPoint

## New chips
- **ColorPt / DblPoint:** in each row, the enemy's front panel becomes MegaMan's if it's solid and nobody stands on it (for 30 seconds, like AreaGrab).
  - A point rises from each panel taken and flies to MegaMan.
  - Each point adds 10 (ColorPt) or 20 (DblPoint) to his next chip, if that chip can take a bonus.
  - With every front panel occupied, nothing is taken.
