# 0.84.0 — FireHit, Boomer and the charge-shot chips

- **FireHit1–3** (family 0x1C sub 8, sub_80CFE08): a fist (t3 0x5B, sprite 0x14/0x1A) on each enemy row of the first enemy column ahead. The panel flashes 10 frames, then the fist hits once. The drop column stops moving after two empty columns, so the fists never land more than 3 columns ahead — an enemy further back is missed, as in the game.
- **Boomer / HiBoomer / M-Boomer** (sub 1, t3 0x32, sprite 0x10/0x07): flies along the bottom row, up the far column and back along the top row, hitting each panel once. Speeds from byte_80CA26C: 8 / 9 / 10 px a frame across.
- **Charge-shot chips** (special sub 38): BugRSwrd, BgDthThd, PunchArm, NeedlArm, PuzzlArm and BoomrArm change MegaMan's charge shot for the rest of the battle (sub_80117BA entries 0x21–0x26): Sword 80, Thunder 40 elec, FireHit 100 fire, AquaNdl 40 aqua, ElcPuls 100 elec, Boomer 100 wood. Lockout 20 after each one.
- The app has no bug frags, so BugRSwrd and BgDthThd always give the 80 / 40 versions, not 200.

204 of 316 BN6 chips. 272 tests pass.
