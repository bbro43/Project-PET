# 0.85.0 — Plus chips from the game, Lance, FullCust

- **Plus chips now join a chip by the game's rule** (custom screen, sub_8029224), not by attack type. A plus chip joins the chip picked just before it if that chip's effect flags allow it, and several can stack on one chip:
  - Atk+10, Atk+30 and WhiCapsl join any chip with flag 2.
  - Navi+20 joins only Navi chips (flag 4).
  - Uninstll joins flag-2 chips that don't have flag 1.
  - DarkPlus is not in the game's list, so it never joins.
  Used alone, each one just pops (0x8010488).
- **Uninstll**: in the game the hit strips the target's programs (SuperArmor, shoes, barrier, B+Left; collision code 0xF8). The app's enemies have none, so for now it only joins.
- **Lance** (sub_80D2596, t3 0x6F): three lances come in from behind the enemies' back column, one per row, and hit that column on frame 6. Sprite 0x0C/0x44.
- **FullCust** (sub_800AF34): fills the custom gauge.
