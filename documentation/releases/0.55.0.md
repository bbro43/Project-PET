# 0.55.0 — Navi Customizer bugs in battle, the game's ability sprites, SuperArmor stops pushes

## Parts list
- Removed the 8 parts that do nothing here: Rush, Beat, Tango (VS only), Collect, Millions, Humor, Poem, SlipRunr (overworld). Saved boards drop them on load.

## Bugs now act in battle (traced in the ROM; see the audit)
- **Processing (type 1):** every move slides MegaMan as far as he can go in the pressed direction.
- **Panel (type 3):** the panel MegaMan leaves can crack: 2, 3 or 4 in 8 by level.
- **Custom (type 4):** from turn 4 / 3 / 2 (by level), the custom screen shows fewer chips each turn, never fewer than 2.
- **Buster (type 7):** a charge shot can misfire. The roll uses the game's table (6, 10 or 13 of 16 by level). What the game's misfire looks like isn't decoded yet.
- **HP (type 9):** MegaMan loses 1 HP every 40 / 35 / 30 frames by level, and faster after each hit (down to every 10), never below 1.
- **Colour bugs (5 or 6+ colours):** the battle starts with one random status for 300 or 600 frames:
  - invisible (attacks pass through, MegaMan flashes);
  - invulnerable;
  - blind (enemies hidden);
  - in a bubble (can't move or attack).
- Emotion and encounter bugs have no effect here. BugStop still prevents all of them.

## SuperArmor
- "Won't be pushed!": WindBox and VacuumFan gusts no longer move MegaMan.

## The game's sprites
- FstBarr's barrier, the Shield / Reflect guard and the bubble now use the game's sprites, decoded on device from the imported ROM.
- Some palette entries in the guard and bubble sprites are placeholders that the game fills from elsewhere. They're drawn transparent, so Reflect shows only in part.
- AntiDmg's star is still app-drawn: the object it spawns turned out to be a sword slash, so the right sprite isn't found yet.

## Tests
- 210 passing (tests/bugs.test.mjs is new).
