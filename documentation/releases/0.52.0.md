# 0.52.0 — Charge shot aura

- **The game's charge aura while B is held** (effect object t4 0x8, chargeShotChargeObject_80E0DF0):
  - pink rays from the 10th held frame (charging, animation 1);
  - a flashing pink core added once fully charged (animation 2).
  - Sprite 0x14/0x08 (0x14/0x15 is used for the other button's charge), palette 2 (effect table 0x80E0398 entry 8: 14 05 02 00), placed at MegaMan's arm offset 0 = (2, 0) (0x80188C0).
  - Decoded on device (registry `chargefx`). The app's old charge bar remains only when no ROM is imported.
- **Charge timing is now rom-verified** (sub_8012EBC, DeterminePowerAttackChargeTime):
  - The charge counts every held frame: charging shows at 10, full at 100.
  - 100 = powerAttackChargeTimes_8020404 row 1 (MegaMan's starting B power attack, Navi stat +5) at Charge level 1. Charge 2–5 give 90 / 80 / 70 / 60.
  - Before this, the app waited 16 frames before starting the count, so a full charge took 116 frames instead of 100.
