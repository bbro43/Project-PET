# 0.49.0 — Folder screens tuned to the game

Matched against the owner's screenshots of Chip Folder and Folder Edit.

- **Chip descriptions from the ROM.** The chip card now shows the game's three-line description ("Cannon to / attack / 1 enemy") in place of the name and MB.
  - Tables: TextScriptChipDescriptions0 (ids 0–255) at Falzar 0x6EB8B8 / Gregar 0x6E983C. TextScriptChipDesc1 (ids 256+) at Falzar 0x6EE0CC / Gregar 0x6EC050.
  - The pointers to both tables are at 0x8027D50 in each version. The game picks the table at 0x811955C.
  - Format: u16 offset table, then one script per chip. Control codes 0xE8 (3 args), 0xF1 (2 args), 0xE9 new line, 0xE7 end; game charmap.
  - 93 ids have blank scripts (unused ids); the card then falls back to name and MB.
- **MB "on the side".** Rows now use the game's small yellow MB digits over the small "MB" label, right-aligned. They come from Folder Edit BG tiles 16–25 (digits) and 26–27 ("MB") at 0x6006800, in BG palette 9.
- **Chip Folder overflow fixed.** The list now starts at y 65 (rows 65–129), so all five rows fit in the panel. The folder name moved to y 49.
- **Selected slot and EQUIP.** The selected slot is filled light blue with blinking orange bracket corners. The EQUIP badge is an orange-rimmed pill above the slot (y 15–24), as in the game. Both are still app-drawn.
- **Description text** is drawn from the battle font's light strokes only, in dark grey, 16 px per line.
- Not done yet: the game's "nMB" next to the folder name (meaning not yet confirmed from the ROM), the 30/30 count box graphic, the cursor and arrow sprites, sorting.
