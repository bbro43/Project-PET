# 0.81.0 — SumnBlk

## New chips
- **SumnBlk1–3:** only works when the panel in front of MegaMan is a hole. Inside the time freeze a dark creature rises from it.
  - It picks an enemy at least 2 columns from MegaMan with a free panel in front of it. When several qualify, the game's own order decides: the nearest it has found so far, then the top-most row.
  - It warps in front of that enemy and slashes the column ahead of it, 3 rows (160 / 200 / 260), then goes back into the hole.
  - Without a hole ahead it does nothing.
