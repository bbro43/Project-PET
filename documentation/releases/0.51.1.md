# 0.51.1 — Battle buttons, finishing-blow animation

- **A and B in battle now match the game:** A uses the selected chip, B fires the buster (hold B to charge). The live version had them the other way round. The custom screen is unchanged: A picks, B takes back.
- **The finishing blow plays out.** When an attack deletes the last enemy (for example Cannon), the battle switched to the win phase on that frame and MegaMan froze on frame 0, so the cannon arm and shot never showed. MegaMan's current attack now plays to its end during the win phase, with no new input.
- **Select and Start** appear only on the folder screens. In battle they pushed the top button row under the d-pad and over the custom window in landscape.
