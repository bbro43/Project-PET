# 0.47.0 — WhiCapsl

- **WhiCapsl** works as in the game: the ROM's chip description reads "Add an effect: Paralyze". Picked after an attack chip (shot, sword, bomb, Vulcan, CrakShot), it attaches paralysis to that chip. Whatever the attack hits is paralysed: its AI stops for the paralysis time and it flickers.
- **Used alone**, WhiCapsl (and Atk+10, which shares chip family 28 subfamily 3, handler 0x8010488) pops the game's capsule puff. That's t4 0x14 (0x80E1CF8), sprite 0x14/0x02 animation 1, 4 px ahead and 48 px up, rising 2 px a frame until the animation ends. The handler does nothing else. Before this, Atk+10 picked alone was dropped.
- Estimated: the paralysis length (120 frames, rules chipParalyzeTicks). The game keeps the timer in collision data +0x1C and counts it down in 0x80175B8 (button presses shorten MegaMan's), but the code that sets it isn't traced. The paralysis flicker is app-drawn.
- Every chip in the starting folder now has its effect.

Tests: 183 passing (new: WhiCapsl tags the attack, the target is paralysed and stops acting; alone it pops). Browser check with the ROM: no errors.
