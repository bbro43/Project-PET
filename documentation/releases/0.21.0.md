# 0.21.0 — 27 Nov 2026 (asset pack 22)

New CPU boss: Bass (BN6), AI entry 19 (0x8101940). Versions and HP as stored in the ROM: Bass 1800, then a 3400 HP version (named BassBX in the ROM's text order) that carries his strongest damage, then 2700 HP versions.
- Moves 3 times between attacks (sometimes 2); the 3400 HP version moves only once.
- Attacks alternate between a basic one and one picked by where MegaMan stands:
  - Hell's Rolling: two dark wheels roll down MegaMan's row (60 / 130 / 90).
  - Shooting Buster: 8 / 6 / 7 rapid shots, the first on MegaMan's panel and the rest anywhere in his area, each lit first (100 / 220 / 150).
  - Earth Breaker (MegaMan at the back): his fist comes down on MegaMan's panel and the 4 around it (150 / 330 / 220). Below half HP it charges for 80 frames first.
  - Dark Arm Blade (MegaMan near the front): steps up and slashes the 2 × 3 area ahead (200 / 450 / 300; 180 / 400 / 270 below half HP).
- Darkness Overload is in the ROM (300 / 670 / 450), but the code only uses it when MegaMan is in a Cross/Beast form, which this app doesn't have yet.

Decoded: the four decision modes, the position checks, every damage, count and timing table.
Estimated: the attack shapes, and the attack visuals (lit panels with a dark burst, plus his own wheel sprite).
Known gaps: he's drawn without his cape (it's a separate sprite layer not composited yet), and the ROM's name order for his versions looks odd, so it's kept as stored.

Asset pack 22: registry adds the Bass sprite and his AI parameters.
Tests: 110 engine/Navi tests + 3 local ROM tests.
