# 0.4.0 — 27 Nov 2026 (asset pack 4)

- New mode: Navi Battle (CPU) with ElecMan and ProtoMan (BN6), all named versions (ElecMan/EX/SP/RV/BX, ProtoMan/EX/SP/BX).
- Navi HP, element and names read from the BN6 ROM tables; attack damage and timings read from each Navi's AI code.
- ElecMan: teleports around his area; ThunderBolt marks MegaMan's panel and strikes it 30 frames later; charged lightning beam along his row.
- ProtoMan: moves 2–4 times, then warps in front of MegaMan for WideSword, LongSword or both; adds a repeated step-in slash below half HP; EX and above raise a guard and counter-slash when hit.
- ElecMan's lightning uses the game's own sprite when a ROM is imported.
- Fix: BN6 fourth virus variant is "SP" (e.g. MettaurSP), not "Ω" — glyph 0x43 per the game's character map.
- Asset pack 4: data/bn6-viruses.mjs now includes Navi stats/names; registry adds ElecMan, ProtoMan and the lightning sprite.
- Tests: 30 engine/Navi tests + 3 local ROM tests.
