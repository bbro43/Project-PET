# 0.44.0 — battle font, BATTLE START!, deletion, ENEMY DELETED!, YOU WIN!

- **Battle font**: the game's 8×16 message font (A–Z, '!', the blue banner bar) is decoded on device from 0x86F133C (Gregar 0x86EF2C0), palette 0x86F2900 (Gregar 0x86F0884). I found it by matching the owner's font sheet against the ROM's tiles (one match). Row 0 of the 'A' tile holds unrelated data, so glyph rows 0–1 are cleared; every other letter has them empty.
- **HP** is drawn in the game's white 8×16 digits (the custom screen's digit set). The box around it is app-drawn.
- **BATTLE START!**: when the first turn's custom screen closes (and at each new survival wave), the bar opens and the message shows, with the battle frozen underneath.
- **Deletion** (0x801746E → 0x80174BE): a deleted enemy plays the deletion burst twice (effect object 3, sprite 0x14/0x03), holds for 21 frames, then dissolves over 32 frames with the game's mosaic (block size t/2) and fade (alpha 16 − t/2). This replaces the white ring.
- **ENEMY DELETED!** after the last deletion, then **YOU WIN!**, both in the game's font.
- Estimated: banner lengths (BATTLE START! 70 frames, ENEMY DELETED! 90) and the bar opening from the middle. The code that runs the banners was not traced. In single player the game goes from ENEMY DELETED! to its results screen; YOU WIN! is the link-battle wording, shown here as requested. The enemy keeps its hurt pose while dissolving; the game uses animation 2.
- Unchanged: enemy names, the chip name at the bottom left and the losing message still use the app font.

Tests: 182 passing (new: BATTLE START! freezes the battle; the deletion timer runs 53 frames). Browser check with the ROM: no errors.
