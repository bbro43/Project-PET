# 0.38.0 — custom screen like the game

- With a ROM, the custom window is now drawn on the battle screen itself, over the left half, with the field still visible on the right, as in the game (no separate pop-up). The custom gauge is hidden while it is open.
- Under the picture: the chip's code letter in the game's big letters (dword_86E2E98), then the element icon, then the damage.
- **Buttons work on the custom screen**: D-pad moves the cursor between the chips and OK, A picks a chip (or confirms on OK), B takes the last chip back, R is Add. Tapping still works (tap a chip to look, tap again to pick, tap OK). Keyboard: arrows, X = A, Z = B, S = R.
- Bigger chip name text in the picture window (app font).

Tests: 178 passing. Browser check with the keyboard (move, pick, confirm): no errors.
