# 0.90.0 — VarSwrd, NeoVari, element swords, DrilArm, WindRack, Recov from the ROM

- **VarSwrd / NeoVari** (families 0x53 / 0x54): hold the chip button and enter a D-pad command within 48 frames. The game's own command lists pick the attack, at the chip's power. Letting go of the button, or running out of time, gives Sword.
  - VarSwrd:
    - ↓ ↘ → → LongSwrd
    - ← ↙ ↓ ↘ → → FtrSword
    - ↑ → ↓ → WideSwrd
    - ↓ ← ↑ → ↓ → LifeSrd
    - ←, buster, →, buster → SonicBom
  - NeoVari:
    - ↓ → ↑ → CrosSwrd
    - ← → ←, buster → SprSonic
    - ↑, buster, ↓, buster, ↑, buster → DblDream
  - For the buster steps, press the buster button while still holding the chip button.
- **SonicBom / SprSonic** (family 0x55): a sword wave covering three rows, moving 8 px a frame. SonicBom stops at the first hit; SprSonic goes through.
- **MchnSwrd / ElemSwrd / AssnSwrd** (family 0x49): strike every enemy that is paralysed (MchnSwrd), standing on grass, ice or lava (ElemSwrd), or either (AssnSwrd). Each strike covers that enemy's panel and the panels above and below.
- **DrilArm**: the drill hits the two panels in front, 3 times, 12 frames apart, and follows MegaMan.
- **WindRack**: hits the column in front, then gusts push every enemy in the three rows back.
- **Recov chips** now heal by the game's table (10, 30, 50, 80, 120, 150, 200, 300) and end at once. **DrkRecov** heals 1000.
- **DarkThnd**: Thunder with 12 moves instead of 5.
