# 0.67.1 — STATUS fonts and the RUN band's layering

- **STATUS fonts:** the screen now uses the game's three fonts, read from the ROM:
  - the bold font for the BUSTER lines;
  - the thin font for FOLDER and PROGRM;
  - the chatbox's own spaced font for "Here is my status."
  All of them use the screen's own palette.
- **RUN band:** it runs its full length again, from the left notch to the arrow on the right. It passes over the programs on the command line, but the window frame and the green screen are drawn on top of it.
