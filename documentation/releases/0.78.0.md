# 0.78.0 — NumbrBl, and Muramasa's cap from the game

## New chips
- **NumbrBl:** time stops and a copy of MegaMan rolls 4 balls down his row, 18 frames apart. Each ball bursts on the first thing it touches. Each ball's damage is the last two digits of MegaMan's HP when the chip is used (HP 87 → 87 a ball).

## Fixed
- **Muramasa:** its damage (the HP MegaMan has lost) is capped at 500, as the game's damage code does. It was 999 before.
