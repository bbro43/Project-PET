# 0.8.0 — 27 Nov 2026 (asset pack 8)

New CPU Navi: ChargeMan (BN6) — ChrgeMan 1000, ChrgeMnEX 1500, ChrgeMnSP 2000, ChrgeMnRV 2000, ChrgeMnBX 2000. The ROM spells his name "ChrgeMan" (8-letter limit), so that's what the HUD shows. Built from his decoded AI code.
- Moves 5 / 4 / 4 / 3 times (by version) between attacks, with a random fast or slow pause.
- Charge strike: warps two panels ahead of MegaMan, winds up for 40 frames and rams the two panels in front (60 / 90 / 120). Repeats 3 or 4 times.
- Target burst: a marker hunts MegaMan for 96 frames, then locks. ChargeMan lines up in that row and fires a burst on the marked panel (100 / 170 / 240). A strike that misses is followed by a burst straight away.
- Game sprites for the marker and the fire burst.

Not simulated yet: the object he spawns at battle start (30 / 50 / 70 damage; behaviour not decoded).
Estimated: hit shapes, marker speed, burst length, and his animation roles (his sprite has 18 sequences, but his code calls animations past that, so the roles are matched by appearance).

Asset pack 8: registry adds the ChargeMan, marker and fire sprites, plus ChargeMan's AI parameters.
Tests: 49 engine/Navi tests + 3 local ROM tests.
