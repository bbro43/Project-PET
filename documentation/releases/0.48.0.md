# 0.48.0 — Chip Folder and Folder Edit from the BN6 ROM

- **New: Chip Folder** button on the menu, opening the game's own screens. Both are decoded on device from the imported BN6 ROM, Gregar preferred (green, as in the owner's screenshots; Falzar's are orange).
  - CHIP FOLDER (chipFolder_initGfx_812386C) shows three folder slots, EQUIP and the folder's first chips.
  - FOLDER EDIT (0x8133EC0) has the folder page and the Pack page with the chip card.
- **How they're decoded** (src/rom/menus.mjs): each screen's palette list and decompAndCopyData list are read as pointers from the ROM and run into a small VRAM / palette / RAM model. The background layers are then drawn from the game's tilemaps:
  - chip folder frame: eTextScript201BA20 and 201BF20;
  - folder edit frame: 201CA20, plus the wide 60×17 panel 2020A20 (the Pack page is the same panel 240 px over);
  - Sort menu: 203486C.
  - The chip card (0x2024A20) is a sprite with its own palette.
  - Compressed blobs start with a 4-byte size word; palette buffers are 0x3001960 (background) and 0x3001550 (sprites).
- **Rows and card contents** use pieces already decoded for battle: chip icons and pictures, the battle text font, the custom screen's code letters, element icons and digits. Their positions are measured from the owner's screenshots. The orange cursor arrow, the slot bracket, the EQUIP badge, the MB number colour and the message box are app-drawn.
- **Folder rules from the ROM**:
  - 30 chips per folder.
  - Copies of the same chip are limited by its MB (sub_8135500): ≤19 MB → 5, ≤29 → 4, ≤39 → 3, ≤49 → 2, otherwise 1.
  - One of each MegaChip and GigaChip, with the game's messages (CompText86CF1A8).
  - The overall caps, 5 MegaChips and 1 GigaChip, are the base values; the game reads them from the Navi's stats (recalled).
- **Controls**:
  - CHIP FOLDER: ◀▶ choose a folder, A edit (an empty slot starts as a copy of folder 1), L/R equip, B back.
  - FOLDER EDIT: ▲▼ move, L/R scroll a page, ◀▶ switch between folder and Pack. A picks a chip; A on a chip on the other side swaps it in. B cancels the pick or leaves (the folder must have 30 chips).
  - Taps: tap a row to select it, tap it again to pick.
- **Saving**: folders are stored on the phone (localStorage), and battles use the equipped folder.
- **Not yet**: chip descriptions on the card (the game's text is compressed text script), sorting (the Sort menu is decoded but not wired), the game's cursor sprites, and the 30/30 count box graphic.

Tests: 186 passing (new: copy limits by MB, Mega / Giga rules, the Pack, battles use the folder given). Browser check with the ROMs: no errors.
