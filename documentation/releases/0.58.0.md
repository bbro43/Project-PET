# 0.58.0 — Chip animations, batch 1: every sword and the GigaCannons

Roadmap step 2 starts here. The game's own hit areas (PanelOffsetListsPointerTable) are now read into the rules, so later chip families can use them.

## Swords (14 new)
Every sword hits the area the game gives it (byte_80EBA18), with the game's slash effect:
- Sword, WideSwrd, LongSwrd
- WideBlde, LongBlde
- FireSwrd, AquaSwrd, ElecSwrd, BambSwrd (with their elements)
- LifeSrd, DrkSword: 2 × 3 panels
- FtrSword: 3 panels long
- CrosSwrd: an X
- DblDream
- StepSwrd: steps 2 panels forward, swings, steps back
- Muramasa: damage is the HP MegaMan has lost, at most 999

## GigaCannons
- GigaCan1–3 use the Cannon / HiCannon / M-Cannon arm. They hit the target and the four diagonal panels around it.

- The elemental swords still use the plain blade sprite.
