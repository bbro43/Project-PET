# 0.41.0 — hit sparks, Recov sparkle, Sword blade, Vulcan firing

All new graphics are decoded on device from the ROM.

- **Hit effects**: hits now spawn the game's hit effect near the target, as t4 0x4 (table 0x80E0804) does, offset by up to ±7 px.
  - Buster: hit effect 0, sprite 0x14/0x05.
  - Charge shot: hit effect 5, sprite 0x14/0x04.
  - Cannon / HiCannon / M-Cannon: t3 0x0 entry 1 (byte_80EBD34), hit effect 7, explosion sprite 0x14/0x01.
  - The offset comes from the frame count, so battle randomness is unchanged.
- **Recov**: effect object 6 (0x800E2FC), sprite 0x0C/0x12, the green streaks on MegaMan. It replaces the "+" glyph.
- **Sword / WideSwrd / LongSwrd**: MegaMan holds the game's blade, t1 0x5 entry 3 (byte_80EBB64), sprite 0x0C/0x00. The game's slash effect is unchanged.
- **Vulcan**: after raising the gun (animation 0xA), MegaMan replays animation 0xD for every shot (0x80EBF6E).
- MiniBomb: the ROM shows that its ball (t3 0x8, parameter 0) spawns no explosion on landing. The splash at 0x80C5C70 only plays when a battle ends mid-flight. The app's landing blast is kept and labelled unverified.

Not yet: Vulcan's per-shot object (t3 0x12), AirShot's hit effect (its t3 0x0 parameter isn't traced), and Sword's wind-up animation 4.

Tests: 180 passing. Browser check with the ROM (buster, Cannon, Vulcan1, Sword, Recov10): no errors.
