# 0.63.0 — Navi Customizer: the colour strip and the RUN animation

## Colour strip
- The colour boxes above the board now show only the colours on the board, in the order they were placed, as in the game (sub_8136644). Unused boxes inside the frame show empty; the two outside it disappear.

## RUN
- RUN now plays the game's sequence:
  1. The yellow chevron band (the game's graphics) runs along the command line.
  2. The parts on the command line light up cell by cell, then all blink.
  3. The band speeds up and narrows away.
  4. The game's message "OK! RUN complete!" closes it.
- The timings are the game's: 20 frames a cell, then 80 frames fast, then 80 frames out.
- If the board has bugs, the app adds a line listing them under the game's message.
