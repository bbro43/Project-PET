## ElementMan element names (correction)
The attack setup routines set the attack element (Unk_02): 0xB = 1 (fire, falling meteors), 0xC = 2 (aqua, sparkles that turn their panels to ice via 0x80D6E70), 0xD = 4 (wood, towers that turn their panel to grass via 0x80D7008), 0xE = 3 (elec). 0.33.0 and earlier had fire / aqua / wood mislabelled; the routines run were already the right ones, so only names, elements and the new panel effects change.

## Shockwaves and holes (0.39.0)
Shockwave type3 0x16 spawns only on a panel with flag 0x10 (0x80C6B64) and, every frame after, destroys itself if the panel under it loses that flag (0x80C6C14). Flags by type (word_3007924): none 0x18000, broken 0x14000, normal 0x10010, cracked 0x10050, poison 0x10110, holy 0x12010, grass 0x10410, ice 0x10810, lava 0x11010, roads 0x10210. So waves stop at holes and cross cracked panels.
