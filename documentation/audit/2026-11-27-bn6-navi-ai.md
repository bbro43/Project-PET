# BN6 CPU Navi AI — ElecMan and ProtoMan (27 Nov 2026)

Tables (Falzar; Gregar found by byte pattern, output identical):
- Navi attributes: pointer table 0x0F24D8; Navi stats: 0x0F253C (Gregar 0x0F3864). Same 6-byte format as viruses.
- Navi AI routine table 0x0F23AC: ElecMan → 0x0F39CC, ProtoMan → 0x0FB9A0. Navi AI index order follows the sprite IDs (HeatMan 1, ElecMan 2 … ProtoMan 11 … ElementMan 16).
- Variant name glyphs: 0x40 RV, 0x41 BX, 0x42 EX, 0x43 SP (bn6f charmap). One ProtoMan variant name uses an unmapped glyph and is hidden in the menu.

## ProtoMan (HP 1800 / 2000 / 2000 / 2800 / 2800, no element)
- Opening phase by variant (table 0x80FBA20): base → routine 0x80FBA24, EX and above → 0x80FBB34. At ≤ 50% HP: 0x80FBA9A / 0x80FBBCA.
- Base pattern: move-counter += 1–2 per move until ≥ 4, then WideSword (0xA) with a 12/16 chance of setting a flag that makes the next one LongSword (0xC); every third attack cycle is attack 0xD.
- EX and above: a second counter leads to attack 0xB, which sets OBJECT_FLAGS_GUARD and counter-slashes.
- Damage tables 0x80FBFFC…: 0xA 100/150/150/220, 0xB 70/100/100/150, 0xC 90/130/130/200, 0xD 150/220/220/330, 0xE 80/120/120/180.
- Timing tables: wait 20/16/14/12, ready 16/14/12/10. Attack routines: vanish 3, appear 3, wait 8, ready animation 0xF, swing animation 5 with sound 0xB0, hold 0x1E.
- Hit shapes are inferred: 0xA spawns sword effect 0x25 with shape argument 6, 0xC effect 0x27 with argument 4, 0xD both effects. In the simulator that's WideSword column / LongSword two panels / both.
- Phase 2 (≤ 50% HP), routine 0x80FBA9A: if MegaMan stands on the danger panels (table 0x80FBE40: middle row, the three panels in front of ProtoMan's area) a counter rises (14/16 chance per decision); at 2 he uses the multi-slash 0xE. Otherwise move counter to 3, then WideSword/LongSword alternate, both swords when the third counter reaches 2.
- EX and above (0x80FBB34): a separate counter leads to the guard stance (0xB), which moves him to a random panel in MegaMan's row (0x80FCD92).
- Target panels: WideSword/LongSword in front of MegaMan (0x80FCD70 — mislabelled as data in the disassembly — and 0x80FCDBA); both swords from his nearest panel in MegaMan's row (0x80FCDDE).
- Slash effect sprite: effect objects 0x25/0x27 load sprite list 0xC index 0x14 (Falzar 0x30F144, Gregar 0x30E6BC). Sequence-to-shape mapping is visual.
- Still estimated: guard duration, exact hit frame, multi-slash repeat details.
