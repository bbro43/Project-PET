# BN6 chips — Phase 1 (0.36.0)

| Data | Where | Notes |
|---|---|---|
| Chip table | ChipDataArr 0x21DA8, 411 × 0x2C (both versions) | chip_data_struct: codes, attack element, chip element (icon), class (library type), MB, damage (AttackPower), family/subfamily, params, lockout, library number, icon/picture/palette pointers |
| Names | text archives at the pointers in 0x27D2C / 0x27D30 | 256 + 168 names; 0xE6-terminated |
| Folders | FolderTable 0x8137868 → 6 folders × 30 u16 (id = v & 0x1FF, code = v >> 9) | folder 0 = the starting folder |
| Chip pictures | record + 0x24 (tiles, 7×6, raw 4bpp) and + 0x28 (palette) | JS decode = Python decode, 0 differing pixels (chips 1, 71, 227, 301, both ROMs) |
| Chip icons | record + 0x20 (2×2 tiles) | palette 0x872CF94 / Gregar 0x872AED0, the one the in-battle chip icon loader uses (0x802707C); custom screen colours not separately confirmed |
| Custom gauge | 0x4000 full, +0x20 a frame (0x801BE70, 0x801DFB8) = 512 frames | FastGauge 0x40, SlowGauge 0x10 (byte_80141A0) |

Gregar differs from Falzar in 40 chip records (its version Navi chips and the Bass chips); stored as overrides in data/bn6-chips.mjs (tools/extract_bn6_chips.py).

Chip effects in this release (behaviour recalled, numbers from the ROM): Cannon family, AirShot, Vulcan1–3, Sword / WideSwrd / LongSwrd, MiniBomb, CrakShot, Recov*, BusterUp, Atk+10. Everything else can be picked but does nothing yet (the custom screen says so). AreaGrab needs area stealing (not modelled yet).
