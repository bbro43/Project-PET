Gregar differs from Falzar in 40 chip records (its version Navi chips and the Bass chips); stored as overrides in data/bn6-chips.mjs (tools/extract_bn6_chips.py).

Chip effects in this release (behaviour recalled, numbers from the ROM): Cannon family, AirShot, Vulcan1–3, Sword / WideSwrd / LongSwrd, MiniBomb, CrakShot, Recov*, BusterUp, Atk+10. Everything else can be picked but does nothing yet (the custom screen says so). AreaGrab / PanlGrab added in 0.39.0 (see the panels audit).

## Chip sprites (0.39.0)
SpritePointersList (off_8002724) category 0x0C holds the chip objects. Confirmed in code and decoded on device:
- 0x13: AreaGrab beam (t3 0xF).
- 0x24: dark bomb (t3 0x4A, 0x80CD50C). It is not MiniBomb: MiniBomb throws t3 0x8, which uses sprite 0x0C/0x02 (corrected in 0.40.0).

Recognised by eye only, not yet traced to the code that loads them:
- 0x08: cannon arm.

## MegaMan's chip actions (0.40.0)
- The player object (0x80EA484) runs actions ≥ 0x10 through AIAttackJumptable (0x80F05F0) at index action − 0x10 (0x80EAF36). object_setAttack5 sets the action to the chip's AttackFamily.
- Attachments are t1 0x5 objects (0x80B8CD8). Each entry is 5 bytes in table 0x80B8BD4: sprite category, sprite index, palette, z shift, arm-offset index. They follow MegaMan and are removed when the attack ends.
- Arm offsets: getBattleArmPositionMaybe 0x8018810 → byte_80188C0. That is 0x44 bytes per form, as (x, z) pairs, indexed by the attachment's last byte.
See releases/0.40.0.md for the per-chip values.

## Effects (0.41.0)
- Effect objects: t4 0x0 (0x80E0548). The effect number goes in r4 → Param1, which indexes byte_80E0398: 4 bytes each, sprite category, sprite index, animation, palette. Recov uses effect 6 (0x800E2FC) → 0x0C/0x12.
- Hit effects: when a collision lands, object_spawnCollisionEffect (0x801A0D8) spawns t4 0x4 with the collision's HitEffect, at the target ±7 px. Table off_80E0804: 4 bytes each. 0 → 0x14/0x05, 5 → 0x14/0x04, 7 → 0x14/0x01.
- Row shots: t3 0x0 (0x80C4E58) entries are 12 bytes at 0x80C4C78; byte 4 is the hit effect. Buster uses entry 0 (Unk_0c = 0), the charge shot entry 6, the cannons entry 1.
- Sword blade: byte_80EBB64[subfamily] → t1 0x5 entry 3 for MegaMan.
- Vulcan (0.42.0): a shot every 11 frames; count dword_80EBFEC[subfamily] = 3/4/5/10. Each shot is t3 0x12, a hitscan moving one panel a frame. Entry byte_80C68D4[0xC] (6 bytes each) = region 2, effect object 0x20 → 0x14/0x0F, at a height chosen from dword_80EBFF0 (8/16/24/32).
- Chip AttackParams (ChipData 0x10) are copied to AIAttackVars Unk_0c (0x802D4F0). AirShot's param 4 → t3 0x0 entry 4 → hit effect 7.
